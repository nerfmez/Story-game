# ภาพตัวประกอบฉบับปรับบุคลิก — งานระหว่างทำ

อัปภาพตัวประกอบชายชุดใหม่ 6 แบบที่สร้างและตรวจภาพแล้ว เพื่อให้เปิดตรวจใน PR ได้ก่อน: ผมเกรียนไหล่กว้าง, รูปร่างท้วม, อ่านหนังสือ, ผมหยิกกำลังคุย, ง่วง และเหม่อเท้าคาง แต่ละแบบมีหน้า หลัง และด้านข้าง

![ตัวประกอบชายชุดใหม่](students-v2-progress.png)

กำลังสร้างนักเรียนหญิงในชุดไทย ม.ปลาย และจะเชื่อมภาพชุดใหม่ทั้งหมดเข้าฉากในคอมมิตถัดไป ภาพฉากที่มีอยู่ในคอมมิตนี้ยังเป็นรุ่นก่อนหน้า ไม่ใช่ผลตรวจชุดตัวประกอบฉบับใหม่
