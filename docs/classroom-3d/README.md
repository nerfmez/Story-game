# ห้องเรียนไทย 3D Pixel — Godot 4.3

ฉากห้องเรียนที่สร้างด้วยโมเดล 3D จริงใน Godot 4.3 ใช้ Compatibility renderer และเรนเดอร์ลง SubViewport 480 × 270 ก่อนขยายภาพแบบ nearest-neighbor ไม่มีภาพห้องเรียนแบนเป็นฉากหลัง โต๊ะ เก้าอี้ บานเกล็ด พัดลม กระดาน และโครงห้องเป็น MeshInstance3D ที่แก้ได้ในเอดิเตอร์

เป็นฉากทดลองแยกจากเกมหลัก ยังไม่ได้ผูกเข้ากับบทสนทนาหรือเปลี่ยนฉากเริ่มเกม

## เปิดฉาก

- ในโปรเจกต์ Story-game: เปิด `scenes/classroom_3d_pixel.tscn` แล้วกด F6
- ในชุดดาวน์โหลดแยก: เปิด `project.godot` ด้วย Godot **4.3** แล้วกด F5
- คำสั่ง: `godot --path . scenes/classroom_3d_pixel.tscn`

ฉากที่บันทึกไว้มีโหนดและวัสดุครบแล้ว ไม่จำเป็นต้องรันตัวสร้างก่อนเปิด

## รายละเอียดฉาก

- ห้องขนาด 10.8 × 12 เมตร สูง 3.6 เมตร
- โต๊ะและเก้าอี้แยก 30 ชุด พร้อมกระเป๋าบางจุด
- หน้าต่างบานเกล็ดฝั่งซ้าย หน้าต่างและประตูทางระเบียงฝั่งขวา
- กระดาน โต๊ะครู ตู้หนังสือ บอร์ดประกาศ นาฬิกา พัดลม และโคมไฟ
- พื้นผิวพิกเซลขนาดเล็ก 32×32 และ texture filter แบบ nearest
- นอกหน้าต่าง: ภาพจากโมเดลตึกเรียน 3D (PR12, `tools/render_classroom_views.gd` ในสาขานั้น) ห้องนี้คือห้องชั้น 2
  ปีกซ้ายของตึก ฝั่งระเบียงเห็นระเบียง เสา และลานข้างนอก ฝั่งบานเกล็ดเห็นด้านหลังตึก (ในโมเดลยังมีแค่สนามหญ้ากับฟ้า)
  แต่ละภาพเป็นแผ่นเรียบห่างกลางห้อง 9.4 ม. ตรงกับโมเดลเมื่อมองจากกลางห้อง (`assets/classroom/view_corridor.png`,
  `view_back.png`) ผนังฝั่งระเบียงเจาะช่องหน้าต่างจริง กระจกใส
- แสงเช้าครึ้มโทนเย็น ไม่มีตัวละครหรือเอฟเฟกต์ฝน
- มุมกล้องอิสระเป็นโหมดสำรวจ ไม่มีการชนผนังหรือระบบเดินตัวละคร

## สร้างฉากซ้ำและรันบนคลาวด์

```sh
godot --headless --editor --path . --import --quit
godot --headless --path . --script tools/build_classroom_scene.gd
xvfb-run -a godot --path . --rendering-method gl_compatibility \
  --audio-driver Dummy scenes/classroom_3d_pixel.tscn -- \
  --capture /absolute/path/view-1.png --shot=0 --no-hud
```

`tools/build_classroom_scene.gd` สร้างและบันทึกฉาก native ที่แก้ได้ทุกชิ้น การแก้สคริปต์ตัวสร้างแล้วรันซ้ำจะเขียนทับไฟล์ฉากนี้ จึงควรสำรองการแก้ที่ทำในเอดิเตอร์ก่อน

ใน repository มี workflow **Godot 4.3 classroom cloud preview** สำหรับโหลดฉากและเรนเดอร์ 3 มุมบน Ubuntu พร้อมแนบภาพและชุดโปรเจกต์แยกเป็น artifact โดยไม่เปลี่ยน GitHub Pages ของเกมหลัก

## ภาพเรนเดอร์

ภาพ view-1.png, view-2.png และ view-3.png มาจาก Godot 4.3 โดยตรง ไม่ใช่ภาพที่สร้างด้วย image generation ต้องตรวจภาพหลังแก้แสง กล้อง หรือโมเดลเสมอ

ข้อจำกัด: นี่เป็นต้นแบบฉากและรูปแบบเรนเดอร์ ยังไม่ได้เก็บรายละเอียดงานศิลป์ระดับภาพอ้างอิงทั้งหมดหรือทดสอบประสิทธิภาพบนมือถือจริง
