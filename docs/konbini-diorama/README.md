# ร้านสะดวกซื้อหัวมุมถนน คืนฝนตก — Diorama 3D แบบ Cel-shaded (Godot 4.3)

โมเดลจำลองขนาดเล็กของร้านสะดวกซื้อสไตล์ญี่ปุ่น "HOSHI MART" ที่หัวมุมถนนในย่านที่อยู่อาศัย ยามค่ำคืนที่ฝนตก
วางอยู่บนฐานไม้สี่เหลี่ยมจัตุรัสเหมือนโมเดลสะสม เรนเดอร์แบบ "3D ที่ดูเหมือน 2D" (cel-shaded) มีเส้นขอบ แสงเป็นขั้น และแสงสะท้อนบนพื้นเปียกแบบภาพวาดอนิเมะ
ไม่มีตัวละครและไม่มี UI บนจอ เป็นฉากแยกจากบทและฉากเริ่มเกม

![มุมหลัก](view-1.png)

## ฉบับประเทศไทย

เปิด `scenes/konbini_diorama_thai.tscn` (หรือ `python3 tools/package_konbini.py --thai`) ได้หัวมุมถนนแบบไทย ใช้โค้ดชุดเดียวกัน ต่างกันที่ `country = "thailand"`

- ป้ายและตัวหนังสือภาษาไทยทั้งหมด: ร้าน "ดาวมาร์ท 24 ชม." ป้าย "ช้าลง" บนถนน ป้ายหยุดแปดเหลี่ยม ถังขยะสีน้ำเงิน/เหลือง/แดง พรม "ยินดีต้อนรับ" บอร์ดประกาศ
- ของไทยหน้าร้าน: มอเตอร์ไซค์ 3 คัน ตู้น้ำดื่มหยอดเหรียญ ตู้เติมเงิน ขอบทางเท้าทาสีขาวแดง ตึกแถวปิดประตูเหล็กม้วนพร้อมป้ายร้านซ่อมมือถือ และสายไฟสายสื่อสารพันกันเป็นมัดพร้อมขดสายและกล่องต่อสาย
- สัญญาณไฟจราจรแนวตั้ง (แดงบน เขียวล่าง) พร้อมตัวเลขนับถอยหลัง
- ในร้าน: ตู้ ATM แทนล็อกเกอร์ ซึ่งนึ่งซาลาเปากับเครื่องย่างไส้กรอกแทนโอเด้ง ตู้บุหรี่ปิดทึบตามกฎหมาย เมนูและป้ายภาษาไทย

## ร้านราเมนใต้ทางรถไฟยกระดับ คืนหิมะตก

เปิด `scenes/ramen_diorama.tscn` (หรือ `python3 tools/package_konbini.py --ramen`) เป็นบล็อกใหม่ทั้งผัง ไม่ได้ใช้หัวมุมถนนของร้านสะดวกซื้อ
ตั้งค่าด้วย `layout = "viaduct"` และ `weather_kind = "snow"` (โค้ดอยู่ใน `scripts/konbini_viaduct.gd`)

- ทางรถไฟยกระดับอิฐแดงพาดผ่านฐาน มีซุ้มโค้ง 4 ซุ้ม: ร้านเหล้า (居酒屋) ร้านราเมน "麺屋 ゆきあかり" ร้านยากิโทริ และที่จอดจักรยานกับตู้กด
- บนสะพานมีรางคู่ เสาและสายไฟเหนือหัว รถไฟ 3 ตู้วิ่งผ่านทุก 24 วินาที ไฟหน้าต่างส่องลงถนน ตัดหายตรงขอบฐานพอดี
- หน้าซุ้มเป็นถนนแคบ ทางเท้ามีเสาไฟฟ้า สายไฟ โคมไฟถนน ราวกั้น และลานจอดรถหยอดเหรียญที่มีรถเล็กหิมะคลุม
- หลังสะพานเป็นซอยแคบกับตึกอพาร์ตเมนต์เปิดไฟบางห้อง แอร์ ท่อดูดควันที่มีไอ
- ใต้ซุ้มแห้ง หิมะตกเฉพาะข้างนอก มีรอยเท้าเดินเข้าร้านราเมน ถนนมีก้อนหิมะเปียกตามขอบ
- ในร้านราเมน: เคาน์เตอร์กับเก้าอี้แดง ชามที่กินค้างไว้ยังมีไอ หม้อซุปกับหม้อต้มเส้นมีไอ ป้ายเมนูไม้ ตู้กดตั๋ว แมวกวัก
- ขอบฐาน: ซ้ายและขวาต่อสะพานรถไฟกับถนนออกไป ด้านหน้าและหลังเป็นลานจอดรถและตึก (ปิด)
- ตัวหนังสือญี่ปุ่นใช้ Noto Sans JP Bold ที่ตัดเหลือเฉพาะตัวอักษรที่ใช้ (`assets/fonts/NotoSansJP-Bold-subset.ttf`, SIL OFL) รายการตัวอักษรอยู่ใน `tools/noto_jp_subset_chars.txt` ถ้าเพิ่มข้อความใหม่ต้องเติมตัวอักษรแล้วตัดฟอนต์ใหม่ด้วย fontTools

## หาดทรายตอนบ่ายฤดูร้อน

เปิด `scenes/beach_diorama.tscn` (หรือ `python3 tools/package_konbini.py --beach`) เป็นบล็อกกลางวันบล็อกแรก
ตั้งค่าด้วย `layout = "beach"`, `time_of_day = "day"` และ `weather_kind = "clear"` (โค้ดอยู่ใน `scripts/konbini_beach.gd` ทะเลใน `shaders/konbini_sea.gdshader` ฟองและทรายเปียกจากน้ำที่ซัดขึ้นหาดใน `shaders/konbini_swash.gdshader` รูปทรงหาดกับจังหวะคลื่นที่ใช้ร่วมกันใน `shaders/konbini_beach.gdshaderinc`)

- แสงแดดมีเงา ท้องฟ้าสีฟ้ามีเมฆลอยช้าๆ เงาอมฟ้าแบบอนิเมะฤดูร้อน
- ร้านริมหาด "海の家 なぎさ" ขายน้ำแข็งไส น้ำโซดาราเมเนะ และยากิโซบะ (มีไอ) ธง "氷" ปลิว ห่วงยางให้เช่า โต๊ะกับม้านั่ง
- ทางเดินไม้จากถนนลงหาด ร่มชายหาด 4 คันกับผ้าปู กล่องน้ำแข็ง รองเท้าแตะ ปราสาททราย ถังน้ำ ลูกบอลชายหาด บอร์ดโต้คลื่น รอยเท้าบนทราย
- หอไลฟ์การ์ดสีขาว ขาสี่ขามีค้ำยัน บันไดมีราวจับจากพื้นทรายถึงชานบน เก้าอี้ใต้ร่มเหลือง ธงปลิว บอร์ดกู้ภัยวางบนทราย ห้องอาบน้ำ
- แถวต้นสนดำญี่ปุ่นริมถนนด้านหลัง ลำต้นโค้งเอนไปทางทะเล กิ่งยาวปลายเป็นแพใบแบนสองโทน
- ทะเลด้านหน้า: น้ำตื้นสีเทอร์คอยซ์ไล่เป็นน้ำเงินเข้ม คลื่นเข้ามาทีละลูกทุก 7 วินาที เป็นแนวขนานกับหาดพร้อมกันทั้งแนว (ไม่ไหลด้านข้าง) ยอดคลื่นสูงขึ้นเมื่อเข้าที่ตื้น กลายเป็นหัวขาวแล้วแตกใกล้ฝั่ง ฟองขาวม้วนเข้าหาฝั่งแล้วแตกเป็นหย่อมๆ จางหายไป ทรายลาดลงไปใต้น้ำและน้ำตื้นใส มองเห็นทรายข้างใต้ จึงไม่มีเส้นขอบน้ำวาดไว้ ขอบน้ำคือที่ผิวน้ำแตะทราย หลังคลื่นแตก น้ำขึ้นไปตามทางลาด ขอบหน้ามีฟองเป็นหย่อมๆ แล้วช้าลงและไหลกลับลงต่ำกว่าระดับน้ำนิ่ง ทิ้งทรายเปียกสีเข้มที่ค่อยๆ แห้ง ด้านข้างและด้านหน้าของฐานเห็นหน้าตัดทรายกับน้ำ แสงแดดระยิบ ทุ่นแนวเขตว่ายน้ำ โขดหินมีฟองล้อม นกนางนวลบินวน
- ขอบฐาน: ซ้ายและขวาต่อหาด แนวน้ำ และถนนออกไป ด้านหน้าเป็นทะเล ด้านหลังเป็นถนน

## ในฉากมีอะไรบ้าง

**ภายนอก** ป้ายร้านเรืองแสงด้านหน้าและด้านข้าง ป้ายเสาสูง กระจกบานใหญ่ ประตูอัตโนมัติ กันสาด พรมเช็ดเท้า
ถังขยะแยกประเภท ที่เสียบร่ม (มีร่มใส) ตู้กดเครื่องดื่ม 2 ตู้ จักรยานแม่บ้าน 2 คัน เสาไฟถนน เสาไฟฟ้า 3 ต้นพร้อมหม้อแปลงและสายไฟระโยงระยาง
ป้ายจราจร (ทางม้าลาย จำกัดความเร็ว 30 ห้ามจอด STOP) ราวกั้นสีขาว ช่องจอดรถพร้อมแท่งกั้นล้อ รางระบายน้ำพร้อมฝาตะแกรง ฝาท่อ
แอ่งน้ำ ทางม้าลาย 2 จุด เครื่องหมายข้าวหลามตัด ตรอกข้างร้าน คอมเพรสเซอร์แอร์ 3 ตัว ลังขวด กระจกโค้งที่ปากซอย
บอร์ดประกาศชุมชน บ้านข้างเคียงที่เปิดไฟชั้นบน ระเบียง กำแพงบล็อก และสัญญาณไฟจราจรที่มุมไกล

**ภายในร้าน** (มองผ่านกระจก) ตู้แช่เครื่องดื่ม 4 บาน ชั้นเบนโตะ แซนด์วิชและโอนิกิริ ชั้นสินค้า 2 แถว (ขนม บะหมี่ถ้วย กล่อง ของใช้)
เคาน์เตอร์พร้อมเครื่องชงกาแฟ หม้อโอเด้ง ตู้อุ่นของทอด และเครื่องคิดเงิน ผนังบุหรี่และเมนูเรืองแสง ชั้นนิตยสารริมกระจก
ตู้แช่ไอศกรีม ตู้ล็อกเกอร์รับพัสดุ เคาน์เตอร์นั่งกินริมกระจก (มีกาแฟที่ลืมไว้และร่มพิงอยู่) ตะกร้า ที่ใส่ถุงร่ม ป้ายระวังพื้นลื่น
สติกเกอร์รอคิวบนพื้น ป้ายแขวนบอกโซน โปสเตอร์ และประตู STAFF ONLY ที่แง้มไปห้องเก็บของ

**การเคลื่อนไหว** ฝนตกต่อเนื่อง (หลบใต้หลังคาและกันสาด สว่างขึ้นเมื่อผ่านแสงไฟ) ระลอกน้ำกระทบพื้น หลังคา และกันสาด
หยดน้ำจากชายคา ระเบียง ตู้กด และป้าย น้ำไหลจากท่อรางน้ำ วงน้ำในแอ่ง น้ำไหลในรางระบายน้ำ หยดน้ำไหลเป็นทางบนกระจก
ป้ายร้านเรืองแสงสั่นเบาๆ และป้ายเสากะพริบเป็นระยะ ประตูอัตโนมัติเปิดปิดทุก 9 วินาที ไอน้ำจากโอเด้งและกาแฟ
สัญญาณไฟจราจรเปลี่ยน เขียว-เหลือง-แดง แบบค่อยๆ เปลี่ยน พร้อมไฟคนข้ามที่กะพริบก่อนเปลี่ยน และแสงสะท้อนบนถนนเปียกที่หันตามมุมกล้อง

## วิธีสร้าง

ฉากสร้างจากโค้ดตอนโหลด ไม่มีไฟล์โมเดลหรือเท็กซ์เจอร์ภายนอก (ใช้แค่ฟอนต์ Sarabun สำหรับตัวหนังสือ)

| ไฟล์ | หน้าที่ |
|---|---|
| `scripts/konbini_kit.gd` | รวมรูปทรงพื้นฐานเป็นเมช สีอยู่ในจุดยอด ข้อมูลเส้นขอบใน CUSTOM0 รวม 3,277 ชิ้นเหลือ 83 mesh instances |
| `scripts/konbini_exterior.gd` | ฐาน ถนน ตัวร้าน และของข้างถนน |
| `scripts/konbini_interior.gd` | ภายในร้าน (render layer 2 รับเฉพาะแสงในร้าน) |
| `scripts/konbini_weather.gd` | ฝน ระลอกน้ำ หยดน้ำ แอ่งน้ำ รางน้ำ แสงสะท้อน |
| `scripts/konbini_camera.gd` | กล้องหมุนรอบ เมาส์ สัมผัส คีย์บอร์ด |
| `scripts/konbini_diorama.gd` | แสง บรรยากาศ ประตู ป้าย สัญญาณไฟ มุมกล้องตั้งต้น และตัวเลือก `country` |
| `scripts/konbini_thai.gd` | ชิ้นส่วนเฉพาะฉบับไทย |
| `scripts/konbini_beach.gd`, `shaders/konbini_sea.gdshader` | หาดทรายกลางวันกับทะเลที่มีคลื่นและฟอง |
| `scripts/konbini_viaduct.gd` | บล็อกใต้ทางรถไฟยกระดับ ทั้งผัง ร้าน รถไฟ แสง และมุมกล้อง |
| `scripts/konbini_snow.gd` | หิมะที่ปกคลุมพื้น หลังคา และของต่างๆ |

| `shaders/konbini_outline.gdshader` | เส้นขอบแบบ inverted hull ความหนาคงที่บนจอ สีเส้นอิงสีวัตถุ |
| `shaders/konbini_reflection.gdshader` | แสงสะท้อนบนพื้นเปียก สว่างสุดที่ตำแหน่งภาพสะท้อนจริงของไฟ แตกเป็นเส้นตามระลอกน้ำ |
| `shaders/konbini_glass.gdshader` | กระจกใส แถบเงาสะท้อน หยดน้ำเกาะและไหลเป็นทาง |
| `shaders/konbini_rain/splash/drip/puddle/steam/sky.gdshader` | ฝน วงน้ำ หยดน้ำ แอ่งน้ำ ไอน้ำ ท้องฟ้า |

2. Import และรัน `tools/test_konbini_diorama.gd`: ไม่มีโหนด UI, กล้องหมุน ซูม เลื่อน และสัมผัสทำงานในขอบเขต, ประตูเปิด, ไฟจราจรเปลี่ยน, ฉบับไทยสร้างได้และตัวนับถอยหลังเดิน
3. เรนเดอร์ 6 มุมกล้องของทั้งสองฉบับ แล้วแนบ PNG และ ZIP ของโปรเจกต์ที่ทดสอบแล้วใน artifact `konbini-diorama-godot43`

## ทดสอบในเครื่อง

```sh
python3 tools/package_konbini.py --output build/konbini
project="$PWD/build/konbini/Konbini-Diorama-Godot43"
godot --headless --editor --path "$project" --import --quit
xvfb-run -a godot --path "$project" --rendering-method gl_compatibility --audio-driver Dummy --script res://tools/test_konbini_diorama.gd
xvfb-run -a godot --path "$project" --rendering-method gl_compatibility --audio-driver Dummy -- --view=0 --capture "$PWD/build/konbini/view-1.png"
```

`--view=0..5` เลือกมุมกล้อง `--capture PATH` บันทึกภาพแล้วปิด `--wait=SECONDS` รอก่อนบันทึก

## ข้อจำกัด

- ตัวหนังสือในฉบับญี่ปุ่นเป็นอักษรละติน (ฟอนต์ในโปรเจกต์ไม่มีอักษรญี่ปุ่น) ฉบับไทยใช้ภาษาไทย
- แสงสะท้อนบนพื้นเป็นแบบวาด ไม่ใช่กระจกสะท้อนจริง จึงไม่สะท้อนรูปทรงของอาคาร
- ฝนตกเฉพาะเหนือฐาน เหมือนโมเดลในกล่อง
- ยังไม่ได้วัดประสิทธิภาพบนโทรศัพท์จริง
